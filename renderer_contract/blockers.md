# Native-resolution blocker ledger

Read [native-resolution readiness](native_resolution.md) for the evidence
boundary. These blockers are capability-specific; optional enhancements do
not block a passive 320x240 capture experiment.

| Class | Resolved foundation | Next material blocker |
|---|---|---|
| A. Loader and interception | Original pre-entry DDRAW selection/clone publication; all-module prefix copies; new source-built forwarder diagnostic | Original-process transparent forwarding and engine first-copy/lifetime observation in a write-isolated environment |
| B. Geometry availability | WORD inputs and narrowed camera DWORD outputs; bounded scalar/batch references and observers, including zero-Z and partial division-fault outputs | Broader batch arithmetic domains, upstream input units and unprojected/cull-rejected geometry |
| C. Vertex/primitive association | Original ENG1 FT4/GT4 fixtures; original ENG3 direct FT4 and TITLE mode-5 FT4; role/time identity despite pointer reuse | Runtime producer observation, production object identity/material provenance, visibility and remaining packet families |
| D. Viewport and precision | Camera precision exceeds final XY; measured single-point path has no rectangle clamp | Selected ENG3 indexed bounds and depth rejects are mapped; bounds meaning, runtime center/focal origin and remaining modules are unresolved |
| E. Image composition | Packet/LUT/upload, movie ID→host decode→pitched indexed copy and palette order, clear/GDI/surface writers mapped | Complete writer triggers and chronological order; slot149 alias reachability and framework writes |
| F. Presentation ownership | Original HWND, surfaces/pitch, present/mode/loss paths; real-system API forwarding in a diagnostic | Original-host coexistence, exclusive final image, resize/mode/loss synchronization and tested shutdown restoration |
| G. Temporal state | Native prior-X/Y overwrite order and static actor/pool fields | Two full simulation updates, stable generation/lifetime, camera discontinuities and pose/animation ownership |
| H. Historical pixel fidelity | Finite original-backed edge/UV/indexed blend fixtures | Broader reachable domains and resource/state timing; this does not prevent proving an upstream geometry seam |

No GPU backend, original-game display takeover or temporal interpolator is
implemented. Captured XYZ is not a universal geometry contract, and a single
opaque legacy framebuffer cannot preserve all world/UI ordering.

## Historical screen-space boundaries

| Target | Established | Remaining |
|---|---|---|
| Passive capture | Shared submission callback, 250-word native prefix copies, per-module OT views, checked packet decoder; original-host sibling DLL selection and clone publication before entry on the tested machine | Production forwarding and actual engine first-copy observation; representative reachable commands; borrowed lifetime; entry snapshots differ from consumption when callbacks mutate future storage |
| Faithful GPU packet rendering | Distinct indexed pixel kernels, finite sprite/triangle/quad/fill geometry, E680 shade/blend/zero-source paths, startup LUT aliasing, forward VRAM move order | Broader coordinate domains; complete reachable command coverage; resource-transition values/timing; callback-driven state changes and full buffer ownership |
| Original window integration | Host HWND, DIB/DirectDraw surface, palette, lock/unlock/present/movie paths; static IsLost/Restore branches | Live coexistence and loss/restoration observations; synchronization with preserved writers |
| Full presentation replacement | Separate palette/movie/remap/clear writers identified | All writer ownership and mode transitions; complete replacement of presentation services |
| Enhanced 3D | Projected XY/UV and earlier camera/projection snapshot identified | Per-vertex association across clipping and modules; depth/perspective/normal information absent from final packets |

The [frame lifetime audit](frame_lifetime.md) establishes allocation requests,
reset/submit/rotation order and cursor associations, without establishing safe
producer capacities. The [surface contract](surface_contract.md) proves finite
lock/unlock/present effects with synthetic services. [Dirty-latch cases](dirty_gate.md)
show why presentation requests need route-specific handling even with no pixel
stores. Live synchronization with movie, palette and transition writers remains
an integration boundary.

Optional 3D enhancements do not block basic capture. Whole-EXE reconstruction
and complete rasterizer reimplementation are unnecessary.

Remaining work is broader coordinate-domain and reachable-command coverage,
shared-state ownership, and resource-driven rectangle/LUT values. Packed U
carry has a finite counterexample to independent Q16 accumulation. A separate
319-sample D60C row-zero fixture shows sampled texel feedback changing a
later V byte; finite CC50 and selected E680 fixtures preserve their tested
sample addresses under the tested source/lookup changes. These route-specific
results do not establish a universal recurrence. The bounded
[pre-entry diagnostic](preentry_publication.md) observes bootstrap publication,
but engine execution, presentation integration and GPU output remain unobserved. Unsupported
packets remain visibly rejected, never silently treated as drawing success.

TITLE's two local context-y upload paths are now tied to the same initial host
context and y=256; indirect mutation is outside the static audit. ENG3's split
state accepts a signed script operand and normalizes only after upload, so
loaded resource values and event/draw order still need evidence. The five
direct primary-callback registrations all clear it; computed installation and
callback write sets remain unresolved.
