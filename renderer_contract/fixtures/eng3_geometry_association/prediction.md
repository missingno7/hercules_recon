# ENG3 FT4 producer association — prediction and falsifier

The initial private plan proposed exercising the static chain `0x22E40 → 0x24770 → 0x8DA0 → 0x231A0` and predicted that its handler path would reach the FT4 producer. Before native execution, the scope was corrected: the upstream visibility/bounds gate is not established, so this fixture does not claim that the path passes or execute those handlers. Static evidence at the callsite `ENG3+0x901D` supplies the cdecl argument roles for a bounded direct entry: resource stream pointer, child/object pointer, and the resource first-byte loop count.

For one explicitly synthetic stream/object/context, the direct original producer at `ENG3+0x231A0` is predicted to build four distinct signed-WORD XYZ triplets. It should send the first three through copied slot 102 (`B430`), transform them through slot 107 (`B320`), then copy the three projected XY lanes through slot 117 (`B5C0`) into packet corners `+0x08/+0x0A`, `+0x10/+0x12`, and `+0x18/+0x1A`. The fourth point should be sent through slots 101/106/114 and stored at `+0x20/+0x22`. The third and fourth point may reuse one scratch address; therefore association is predicted by the producer-built pointer, callback order, and packet-memory destinations, not by coordinate equality. The producer should write tag `0x2e`, advance the observed cursor by `0x28`, and link the packet through its selected ordering-table bucket. Material and texture fields will be reported only when supported by executed native reads and stores.

Falsifiers: (1) direct entry fails to return through the pinned producer span; (2) any source point cannot be linked by its actual pointer and callback order to the captured camera/projected lane and packet corner; (3) the reused scratch address does not show the expected overwrite before point four; (4) native packet tag, cursor advance, source reads, or OT writes disagree with the observed producer instructions; or (5) execution leaves the pinned original-code spans, requires a fabricated callback result, writes original code, or reads outside the mapped images and explicit synthetic records.

All stream/object/context/matrix/view/packet/OT bytes are synthetic. The direct producer execution does not prove the upstream gate, visibility result, live object or mesh identity, asset semantics, coordinate units, global capacity, full module behavior, rasterized output, or GPU behavior. Observed cursor movement and finite arena sizes are not capacity guarantees. Executed spans do not change canonical recovery state.
