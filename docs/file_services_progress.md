# Host file services and engine bridges

The continuation adds twelve ordinary C functions covering 1,328 target bytes:
six host file services (1,152 bytes) and six engine interface bridges (176 bytes).
These are experimental reconstructions in `calibration/`, not accepted matches.
`recovery.json` remains unchanged at 41 matched instances and 4,368 bytes.

The host services preserve live context/handle reloads, captured synchronous
requests, reopen retries, wrapped signed sector rounding, signed progress counts,
unsigned countdown and the observed completion/failure callback order. Their
49-check fixture passes. All six complete contributions remain nonexact; no
source spelling grid follows this measured family. The cancel return prototype
remains uncertain: its physical target returns zero, but known callers ignore it
and the current source uses `void`. Filename capacity and full context extent are
unproved. The external host context pointer denotes slot 1 of the source table;
the source does not define fictitious overlapping storage to close linkage.

The shared context header now describes the observed prefix through offset
`0x1b04`. Its callback fields allow both observed historical C call forms:
engine calls without arguments and host calls with one zero argument. This does
not prove original prototypes. Fresh compilation preserved the complete bytes
and ordered relocations of all seven existing header consumers. Included-header
hashes are recorded separately because the exploration recipe ID does not hash
includes; neither identity is an acceptance cache.

The engine bridges use one native 32-bit view of the copied 250-word interface,
with the context pointer at slot 1. The six members forward async load, cancel,
compact, length, sync load and allocation. All 176 bytes are relocation-normalized
equal; each wrapper still has one unresolved table-member DIR32 relocation and
none is a raw match. The eight-check fixture includes a live callback replacement.
Integration preserved both regions' private candidate bytes and ordered
relocations. Original table extent beyond the copied prefix and TU ownership
remain unproved.

The separate-TU host/archive fixture links all nineteen reconstructed services
and archive functions, plus the two accepted empty callback/diagnostic bodies,
using historical stdio. A synthetic archive and callback observations are test
boundaries. Its 28 checks cover length, synchronous load, async busy state,
progress, completion countdown and failure cancellation. The composed source
preserves a concrete behavior: the archive clamps a read to four bytes, while
host progress advances the destination by the requested 2,048-byte sector.
Original game files and executables are never executed.

Current validation passes 43 semantic suites with 3,647,754 checks, 30 Python

`evidence/file_services_validation.json`; the compact ABI/static contracts are
