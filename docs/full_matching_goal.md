# Full matching reconstruction goal

The active goal is a full matching reconstruction of the 1997 PC Hercules game:
TITLE.DLL, ENG1.DLL, ENG3.DLL and HERCULES.EXE, using the existing PC oracles and
pinned historical compiler/linker/libraries. Strict actual byte equality comes
first. Preserve useful non-strict source when a measured compiler family reaches
diminishing returns, then continue independent recovery rather than replaying it.

GPT-6 Luna xhigh handles bounded mechanical recovery, compilation and dependency
checks. GPT-6.1 Sol high handles uncertain source representation, shared compiler
mechanisms and compilation-unit/data ownership. Workers use disjoint private
lanes; one integrator changes canonical source, recovery state and commits. This
is the user's requested allocation, not a difficulty score or routing ledger.

`recovery.json` alone grants function recovery state. Maintain separate raw,
masked, reconstructed and missing-source diagnostics with the existing tools.
Relocation-masked equality does not become strict acceptance. Fresh builds,
complete extents, coherent bindings, original hashes and protected-peer regression
remain required. No assets edits, copied machine code, arbitrary assembly,
placement tricks, dummy contributions or weakened gates are permitted.
