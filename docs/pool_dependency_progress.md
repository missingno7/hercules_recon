The accepted total remains **40 instances / 4,352 bytes**. Fresh historical
compilation preserves every accepted raw match. The following sources are
experimental calibration; no new recovery entry was accepted.

The full-mask comparison at three independently decoded sites distinguishes
descriptor tests from the allocator's ordinary flag tests. Changing those three
expressions produces a complete **96-byte coalescer with relocation-normalized
equality** in `calibration/host_pool_repaired.c`. Save-arena remains normalized
equal; initialize and free retain their complete previous contributions. The
allocation residual remains unresolved. The old baseline and stopped masked-stride
family remain available; equal contributions are frozen for linkage work.

`evidence/actor_pool_layout.json` grounds three nested actor views of 148, 236 and
308 bytes. The provider actually requests `normal_count*308`,
`middle_count*236+308`, and `alternate_count*148+308`, all with flag `0x10`.
The extra 308-byte tails have unknown purpose. Counts come from configuration
records; synthetic fixture dimensions do not establish physical capacities.
Normal pool output slot `ENG1:0x72860`, previously provisionally called `g_focus`,
is a pool base. Existing equal consumers access element zero; its gameplay role
and original name remain unproved. Their source is preserved.

The five-function first family in `calibration/actor_pools.c` includes both
allocators and the complete alternate -> middle -> normal initializer chain.
The **176-byte middle initializer is relocation-normalized equal**. Both scans
compile to 28 blocks against 26 in the target, falsifying the topology prediction.
Alternate and normal initializer code generation also remains unresolved; no
spelling grid followed. The fixture passes 262,408 checks, covering all 16-bit

`calibration/host_pool_lifecycle.c` expresses bulk free and reverse compaction.
The first fixture exposed an incorrect owner-slot access in descriptor word zero.
The directly decoded owner is word one at +4; correcting those three accesses
passes 34 checks. Its **16-byte compaction wrapper is normalized equal**; bulk
free and compaction remain unmatched. Synthetic helper models are test fixtures,
not accepted implementations or original runtime observations.

Two copy dependencies must remain distinct. The complete 821-byte implementation
at CD EXE `0x10fb0` is historical CRT copy code: all non-relocation bytes and all
46 resolved section-local operands agree with pinned VC5 RTM members. Both
`memcpy` and `memmove` in LIBC and LIBCMT contain identical executable code here;
this evidence cannot select their public name, runtime variant or linker flags.
`python scripts/crt_copy_evidence.py` reproduces the identification without
patching any object or executing an original.

The 176-byte helper at `0x43a0` is a separate project reverse-DWORD copy dependency.
Its first ordinary-C family has the same six-block CFG and passes 1,772 checks,
but 171 raw bytes differ. The source rounds the signed byte count and stages
eight-word backward groups; its group division emits SAR where the target uses
SHR after a positive-count guard. This is a possible independent type discriminator,
not permission to tune register allocation or sweep equivalent spellings.

The single guarded unsigned-group experiment then emitted the target SHR and
retained all 1,772 fixture checks. The full contribution still differs in 172
bytes; only the count-operation discriminator was confirmed. Its recipe and
stopping condition are published without replacing the first baseline.

An independent static audit found identical offsets, widths, values and order
for all 107 actor initializer stores (58 alternate, 26 middle, 23 normal). This
does not prove original signedness or pointer-versus-integer declarations.
